# Overload — DevOps Showcase Project

A workout tracker (React + Vite) used as the application for an end-to-end DevOps pipeline.

## Stack (planned)
| Area | Tool |
|------|------|
| App | React + Vite |
| Containers | Docker |
| Infrastructure | Terraform on AWS |
| Config management | Ansible |
| Orchestration | k3s (Kubernetes) on EC2 |
| CI/CD | Jenkins |
| Monitoring | Prometheus + Grafana |

## Run locally
cd app
npm install
npm run dev
